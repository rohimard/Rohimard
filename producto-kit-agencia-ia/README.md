# Kit de Lanzamiento: Agencia de IA

Sistema completo para lanzar y vender servicios de automatización con IA, sin necesitar equipo ni inversión inicial.

## Contenido del kit

1. **Guía de lanzamiento en 7 días** (`1-GUIA-LANZAMIENTO-7-DIAS.md`) — de cero a tu primera propuesta enviada
2. **50 prompts listos para servicios de IA** (`2-PROMPTS-SERVICIOS-IA.md`) — organizados por categoría de servicio
3. **Plantilla de propuesta comercial** (`3-PLANTILLA-PROPUESTA-COMERCIAL.md`) — lista para copiar y personalizar
4. **Calculadora de precios y paquetes** (`4-CALCULADORA-PRECIOS-PAQUETES.md`) — 3 niveles de servicio con precios sugeridos
5. **Scripts de ventas y outreach** (`5-SCRIPTS-VENTAS-OUTREACH.md`) — mensajes, llamadas y manejo de objeciones
6. **20 herramientas de IA rentables** (`6-20-HERRAMIENTAS-IA-RENTABLES.md`) — qué usar y qué cobrar por cada una
7. **Checklist de lanzamiento 30 días** (`7-CHECKLIST-LANZAMIENTO-30-DIAS.md`) — plan de acción día a día

## Este es el producto que se vende

Este folder completo (los 7 archivos en Markdown, convertibles a PDF) es el entregable digital. Ver `LANDING-COPY.md` para el texto de la página de ventas y `PLAN-DE-VENTA.md` para los pasos exactos de publicación y distribución.
