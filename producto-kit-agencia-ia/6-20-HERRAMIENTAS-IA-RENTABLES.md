## Cómo elegir tu stack inicial (no uses las 20 de una vez)

Para tu primer cliente, el stack mínimo viable es:

**n8n (o Make) + API de Claude/OpenAI + WhatsApp Business API + Google Sheets**

Esto te permite entregar el paquete Starter completo sin sobre-complicar el proyecto ni tu curva de aprendizaje. Agrega herramientas nuevas solo cuando un cliente específico lo requiera — no construyas capacidades que todavía no has vendido.
