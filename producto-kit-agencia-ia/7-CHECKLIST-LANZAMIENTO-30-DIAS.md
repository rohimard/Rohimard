# Checklist de Lanzamiento — 30 Días

## Semana 1 — Fundamentos
- [ ] Día 1: Elige tu nicho (ver Guía, Día 1)
- [ ] Día 2: Define tus 3 paquetes de precios (usa la Calculadora)
- [ ] Día 3: Monta tu stack básico (n8n/Make + API de IA + WhatsApp)
- [ ] Día 4: Construye tu demo funcional
- [ ] Día 5: Escribe tu propuesta comercial base
- [ ] Día 6-7: Lista tus primeros 20 prospectos (conocidos + negocios locales)

## Semana 2 — Primer contacto
- [ ] Contacta a los primeros 10 prospectos (usa los scripts)
- [ ] Agenda al menos 3 llamadas de descubrimiento
- [ ] Publica en 1-2 grupos/comunidades relevantes aportando valor primero
- [ ] Ajusta tu demo según el feedback recibido

## Semana 3 — Cierre
- [ ] Realiza las llamadas de descubrimiento agendadas
- [ ] Envía propuestas dentro de las 2 horas siguientes a cada llamada
- [ ] Haz seguimiento a las propuestas enviadas (día 2, día 5)
- [ ] Cierra tu primera venta (o ajusta oferta/precio si no hay avance)

## Semana 4 — Entrega y siguiente ciclo
- [ ] Entrega el proyecto exactamente según lo prometido
- [ ] Pide testimonio/reseña en cuanto el cliente vea resultados
- [ ] Documenta el caso como "caso de éxito" para la siguiente propuesta
- [ ] Contacta 10 prospectos nuevos usando el caso de éxito como prueba social
- [ ] Sube el precio del siguiente paquete en 20-30%

---

## Señales de que algo no funciona (y qué ajustar)

| Síntoma | Ajuste probable |
|---|---|
| Nadie responde tus mensajes | El nicho es muy amplio o el mensaje es muy genérico — personaliza más |
| Responden pero no agendan llamada | Tu propuesta de valor no es clara — enfócala en un problema, no en "IA" |
| Agendan pero no compran | Falta la demo o el precio suena a "depende" — cierra el alcance y el precio |
| Compran pero regatean mucho | Estás vendiendo a un nicho sin presupuesto — sube de segmento |
| Vendes pero el proyecto se alarga sin fin | El alcance no estaba cerrado por escrito — usa siempre la plantilla de propuesta |
